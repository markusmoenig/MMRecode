# Bundled MMFX fonts

`Inter.ttf` is the Inter variable font distributed by the Google Fonts repository. It is included
to provide a portable, deterministic first MMFX text example rather than relying on a font installed
on the rendering machine.

- Source: `https://raw.githubusercontent.com/google/fonts/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf`
- SHA-256: `29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031`
