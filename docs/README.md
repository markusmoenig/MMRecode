# MMRecode website

The documentation site for [MMRecode](https://github.com/markusmoenig/MMRecode), built with Docusaurus 3.

## Local development

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

The static site is emitted to `build/` and configured for `https://mmrecode.com`.

Documentation pages live in `docs/`. Keep them concise and update the detailed root design documents and crate READMEs when implementation details change.
